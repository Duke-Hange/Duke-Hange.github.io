# Hang Yu 个人主页项目

这是一个现代、响应式的个人主页，专为展示您的学术经历和研究成果而定制。该主页参考了先进的学术主页设计，结合您的脑科学研究员身份进行定制。

## 项目结构

```
个人主页/
├── index.html              # 主页面文件
├── README.md              # 项目说明主文档
├── images/                # 图像资源目录
│   ├── bg.jpg            # 页面背景图片
│   ├── hangyu.png        # 个人头像
│   ├── Schools/          # 学校/机构标识目录
│   └── publications/     # 发表物封面目录
```

## 主要特性

- **响应式设计**: 支持桌面、平板和移动端显示
- **学术导向布局**: 突出教育背景、研究经历和学术成果
- **现代化视觉效果**: 包含悬停动画和视觉反馈
- **专业技能展示**: 表格形式直观展现技术能力

## 快速上手

### 环境要求
- 任何现代Web浏览器（Chrome, Firefox, Safari, Edge）
- 无需服务器，可在本地打开index.html预览

### 配置步骤
1. 下载整个个人主页项目文件夹
2. 准备好 `images/` 目录下的所有图片资源（遵循 `images/README.md` 中的指南）
3. 在浏览器中打开 `index.html` 验证显示效果
4. 根据需要编辑 `index.html` 来更新您的最新信息

## 内容板块

- 标题: Roboto Bold, Noto Sans SC Bold

## 更新维护

### 新增教育/工作经历
在 HTML 的对应 `section-card` 部分，参照现有 `exp-item` 结构添加新的经历。

### 添加学术成果
在发表物部分，参考现有 `publication-item` 结构，添加新的学术作品。

### 更换个人资料
- 更新 `sidebar` 部分的基础信息
- 修改 `About me` 部分的内容
- 确保 `social-links` 中的链接正确

## 常见问题

Q: 图片无法显示？
A: 检查图片路径是否正确，并确认图片文件已放置在指定目录中

Q: 如何添加新的社交链接？
A: 在 `social-links` div 中添加带有Font Awesome图标的链接

Q: 响应式设计在某些设备上显示异常？
A: 检查 `@media` 查询部分，适当调整断点值
