01 / 智能体与理性

什么算一个好决定？

评价行动之前，先说清目标、环境和能够获得的信息。

学完这一节，你可以：说明智能体依据什么行动，区分任务目标与一次结果，并算出一个简单选择的期望效用。

学习准备：先区分动作、结果和评价标准。这里会用概率加权来比较尚未发生的结果。

能够感知环境并选择行动的系统，称为智能体。配送机器人通过传感器获取信息，再通过轮子、机械臂等执行器行动。评价它之前，需要先说明任务要求。

材料需要按时送达。直达路线较短，但门可能关闭；绕路较稳妥。若选择直达后恰好迟到，能否仅凭这一次结果判断先前的决定不合理？

先区分选择与结果

评价一个决定，要回到作决定时能够获得的信息。先列清可选动作、可能结果和评价标准，才能讨论这个选择是否合理。PEAS 是整理任务条件的一种方式，分别指表现标准、环境、执行器与传感器。

PEAS 要素在材料配送中需要避免的混淆
P：表现标准（Performance measure）按时送达、材料完整、减少耗电到达目的地不等于完成全部目标
E：环境（Environment）房间、走廊、门、其他人员环境不等于智能体当前看到的内容

一起算一次：选择发生在结果之前

为了练习，把任务表现压缩成一个效用分数，分数越高越好。直达路线以 0.8 概率按时到达，效用为 10；以 0.2 概率迟到，效用为 −5。绕路则确定获得效用 6。两条路线的分数使用同一个评价尺度。

列全可能结果

直达有按时、迟到两种结果。它们的概率之和为 0.8+0.2=1，说明这里没有漏掉其他情况。

分别计算概率加权

按时部分为 0.8×10=8，迟到部分为 0.2×(−5)=−1。负号表示这个结果不利，不表示概率为负。

相加并比较

EU(直达)=8−1=7；EU(绕路)=1×6=6。按给定概率与效用，直达的期望效用更高。这里的 7 是比较行动的平均意义指标，实际一次只会出现 10 或 −5。

公式里的 ∑ 表示“把列出的各项加起来”，下标 o 表示对所有结果求和；P(o | a,I) 中竖线右侧说明给定的动作与信息，不表示除法。即使直达这一次恰好迟到，仍须回到当时的概率和评价标准，才能判断原来的方法是否合理。

完成后核对：怎样得到 4 次动作的路线？

(C,0) → (K,0) → (K,1) → (C,1) → (L,1)。依次是左移、取物、右移、右移。取物虽没有改变位置，仍占一次动作；四次动作各付出 1，总代价为 4。至少要走到 K、取物，再经 C 到 L，因此不能再少。

为什么“只记录位置”的搜索可能失败？

如果搜索器已经访问了 K，那么“在 K 取物”之后仍被编码为 K。全局重复状态表可能把这个新情况当作旧情况丢弃。真正需要保留的是 (K,0) 和 (K,1) 的区别。问题出在表示丢失了信息，而不是 BFS 不会找路径。

先理解三个操作，再读算法名称

下面会比较三种基本方法：广度优先搜索（Breadth-First Search，BFS）、深度优先搜索（Depth-First Search，DFS）和一致代价搜索（Uniform-Cost Search，UCS）。它们最直接的区别，是怎样安排等待检查的候选。

一个搜索节点可以看成一张行程卡片：除了写当前位置，还记着从哪里来、已经花了多少代价。把一张卡片拿出来检查，称为“弹出”；根据它生成下一步的卡片，称为“展开”；暂时保留等待检查的卡片，构成“边界”。这里的边界是一份候选记录，不是地图的外沿。

变量或结构含义
n，s搜索节点 n 记录状态 s、父节点和路径信息；同一状态可出现在不同搜索节点中
d(n)，g(n)从根到 n 的边数；已走路径的累计代价
边界 frontier已经生成，但还等待检查或展开的节点
展开根据当前节点生成后继；本页弹出目标后立即停止，不展开目标

四种搜索共用的一套过程

把搜索看成不断维护候选记录的过程。地图描述可能发生什么，边界记录哪些路径还值得继续检查。

  1. 初始化：把起点记录放进边界，累计代价为 0。
  2. 取出候选：按当前算法的规则，从边界取出一条记录。
  3. 检查目标：若已到目标，沿父记录恢复动作序列；这里采用弹出时检查。
  4. 展开后继：枚举合法动作，计算新状态与累计代价。
  5. 处理重复并继续：决定哪些记录应保留、更新或跳过，再回到第 2 步。边界耗尽而没有目标，才返回失败。

“后继怎样生成”来自任务模型；“下一次取谁”来自搜索策略。BFS、DFS、UCS 与 A* 都需要前者，主要在后者及重复处理规则上有所不同。

算法边界的组织优先检查什么
广度优先搜索（BFS）先进先出的队列边数最少的候选路径
深度优先搜索（DFS）后进先出的栈当前分支更深的位置
一致代价搜索（UCS）按 g 排序的优先队列累计代价最低的候选路径

用两步操作理解队列和栈

BFS 把新卡片放在队尾。展开 S 后队列是 [A,B]；拿出 A，再把它的后继 C 放到末尾，得到 [B,C]。较浅的候选不会被刚产生的更深候选插队，所以搜索按层推进。

DFS 则让最新发现的后继优先被检查。按照这里的约定，展开 S 后先检查 A；A 的后继 C 又排在仍然等待的 B 之前，于是沿着一个分支持续深入。一个分支走不通，再返回尚未检查的分支。

UCS 比较的是累计代价。走两步每步耗电 1，与走一步耗电 5，相比之下前者更便宜。因此 UCS 可能先检查更深但更便宜的路线。它选择最小 g 的规则来自最低代价目标，与“先入队”或“后入队”无关。

推导与计算

BFS 与 UCS 的最优性来自什么

BFS 最小化深度。设深度 d 是从起点到节点的边数。队列先处理第 d 层，再处理第 d+1 层，所以第一次弹出的目标不可能比另一个尚未处理的目标更深。若每条边代价都是相同的正数 c₀，则：

g(n)=d(n)c₀
d₁<d₂ ⇒ d₁c₀<d₂c₀　(c₀>0)

因此等代价时，最少边数也保证最低代价。边代价不同时，这个推论失效：原地图中，两条路线分别是 2 步、代价 7，与 4 步、代价 4。BFS 仍保证前者的步数最少，却不保证耗电最少。

UCS 最小化累计代价。假设边代价非负，边界保留到同一状态的更便宜路径，且目标在弹出时检查。反设弹出的目标 G 代价为 C，却还存在总代价 C*<C 的路线。该更优路线必有一个尚在边界的前缀 n；由于后续边代价非负：

g(n) ≤ C* < C=g(G)

UCS 必须先弹出较小的 g(n)，不可能先弹出 G，产生矛盾。这解释了为什么“刚生成目标就停止”缺少保证。这里讨论有限图；若允许负边，前缀代价不再是完整路径的下界，这个证明也就不能直接使用。

深入阅读｜搜索树为什么会迅速变大？

搜索量为何增长得快？

用 B 表示每个节点的后继数，d 表示深度。对一棵每层完整展开、没有合并重复状态的 B 叉树，第 i 层有 Bi 个节点。到第 d 层为止的节点数为：

Nd=1+B+B²+…+Bd
B·Nd−Nd=Bd+1−1
Nd=(Bd+1−1)/(B−1)　(B>1)

第二行把原式乘 B 后相减，中间项抵消；B=1 时单独得到 Nd=d+1。若 B=3、d=4，则 N₄=(243−1)/2=121，而最深一层已有 81 个节点。深度增加一层，最深层规模乘 3。

这是完整树的节点计数，不是所有程序的精确运行次数。BFS 可能因队列和已生成的下一层保存大量候选；DFS 通常少保存同时等待的分支，但沿着无限深的路径可能一直深入。图搜索还要另外计入重复状态记录。

心理学观察：选择顺序相同，就使用了同一种算法吗？

一个人在这张小图中先探索 A，可能来自深度优先、目标方向偏好，或过去经验。单次路线不能唯一确定内部过程。可以改变目标位置、分支深度或代价，并记录选择顺序与回看次数，检验不同解释是否给出不同预测。

BFS 的边界顺序由生成顺序与层次决定，不使用边代价排序。路线可能不变，累计耗电却会变；这两件事要分别报告。

把总代价拆成已知与未知两部分

只看离目标多近，会忽略已经绕了多远。用 g 记录已付代价，用 h 估计剩余代价，相加得到总成本估计 f。先区分这三个量，再讨论估计需要满足什么条件。

符号含义与来源
g(n)从起点沿当前路径到 n 的实际累计代价
h(n)从 n 到目标的剩余代价估计，由启发函数计算
h*(n)真实最低剩余代价；通常未知，用来定义或检查估计的性质
f(n)=g(n)+h(n)经当前节点到达目标的总成本估计

小写 n 表示一张搜索节点卡片；n′ 表示它的一步后继，右上角的撇号只是区分前后两个节点。g 依赖到达该状态的具体路径：同一个房间从不同路线到达，已经花费的代价可能不同。h 通常根据当前状态和目标计算，不必把整段来路再算一遍。

先解释相加的依据，再解释选择规则

真实总代价等于已付代价加剩余代价；未知的剩余部分用 h 估计，就得到 f=g+h。相加的两项必须同单位。

“取 f 最小的节点”是 A* 的算法规则；“这条规则能找到最优路径”则是需要条件支持的性质。把两者分开，才能理解为什么某些随意设计的 h 虽然也能放进公式，却没有最优性保证。

什么条件让估计可信？

可采纳性

0 ≤ h(n) ≤ h*(n)

不会高估最低剩余代价。它给的是下界，不是“通常比较准”这个模糊评价。

一致性

h(n) ≤ c(n,n′)+h(n′)

对每条边都满足，并且目标 h(G)=0。估计不能比“先走一步，再估计”还大。

深入阅读｜从一致性理解 A* 的最优性
推导与计算

从一致性推到 A* 的最优性依据

先看局部性质。记 c(n,n′) 为一步代价；g(n′) 使用经 n 到达 n′ 的这条路径计算。一致性要求 h(n)≤c(n,n′)+h(n′)。把这条不等式代入 f：

f(n′)=g(n′)+h(n′)
=g(n)+c(n,n′)+h(n′)　累计代价定义
≥g(n)+h(n)=f(n)　一致性条件

因此 f 沿展开路径不下降。原通道图 S→A 的代价是 1，h(S)=4、h(A)=3；f(S)=0+4=4，f(A)=1+3=4，恰好相等。一致性允许相等，不要求严格增加。

再看从起点到目标的整体保证。设 C* 是最优路径总代价；n 是最优路径上保留了最优前缀的边界节点。若 h 不高估最低剩余代价 h*，则：

f(n)=g(n)+h(n) ≤ g(n)+h*(n)=C*

等号成立是因为 n 在最优路径上，且 g(n) 对应其最优前缀。若算法先弹出一个更贵的目标 G，因为目标 h(G)=0，就有：

f(G)=g(G)>C*≥f(n)

这与 A*“弹出最小 f”矛盾，因此它不能先弹出更贵的目标。关键不仅是 f=g+h，还包括更优路径的前缀没有被错误丢弃。

这里的最优性条件：有限图、非负边代价、目标估值为 0、边界保留更小 g、弹出时检查目标，且 h 一致。一致性使已扩展状态无需重开。若只要求可采纳而不一致，一般要允许发现更小 g 时重新展开；否则上面关于最优前缀被保留的前提可能失效。

从行动序列转向变量赋值

约束满足问题（Constraint Satisfaction Problem，CSP）把任务写成变量、取值范围和必须满足的关系。求解的目标是找到一组合法赋值。

排班的答案是一组同时满足要求的取值。我们用变量表示测试时段，用域列出候选值，再用约束排除不合法的组合。

本例条件：三项测试 A、B、C 各占一个时段。A 与 B 共用设备，不能同时；C 必须在 B 之后；A 不能排在时段 3。A 与 C 可以同时。

CSP = (X,D,𝒞)X 是变量集合，D 给出各变量的取值域，𝒞 是约束集合。测试名称 C 是其中一个变量，与花体 𝒞 表示的约束集合不同。
组成本例
变量 X{A,B,C}，各表示相应测试的时段
域 DD(A)={1,2}；D(B)=D(C)={1,2,3}
约束 𝒞A≠B；B<C
约束图A—B—C；没有 A—C 边

怎样从一句要求得到一个约束

“A 不能排在时段 3”只涉及 A，可以直接从它的初始域删除 3；“A 与 B 不能同时”涉及两个变量，写成 A≠B；“C 必须在 B 之后”说明 C 的数字更大，写成 B<C。符号 < 表示严格小于，所以 B=C 也不被允许。

一次给变量选择一个时段，称为赋值。把某个变量所有暂时还可尝试的值放在一起，就是它的当前域。域里的值有时只满足已检查的局部要求，并不保证一定能延伸成完整解；后面的 B=3 分支会说明这一点。

先理解回溯，再决定怎样选得更好

当前安排是一组部分赋值。每次给一个尚未安排的测试选时段，检查约束，再继续处理剩下的变量。遇到冲突时，撤销最近仍有其他选项的决定，恢复依赖它删去的候选，然后换一个值。

例如先选 A=1，再选 B=3，会使 C 无处可排。撤销 B=3 后，A=1 仍保留；尝试 B=2 就允许 C=3。这里改变的是尝试顺序，原来的合法解集合没有改变。MRV、度启发式与 LCV 都是在这个共同过程上安排搜索顺序。

搜索时要分开回答两个问题：先排哪项测试，以及先给它试哪个时段。MRV 和度启发式帮助回答第一个问题，LCV 帮助回答第二个。下面先了解它们的规则，再到排班台尝试。

先选变量：MRV

Minimum Remaining Values：优先选择剩余合法值最少的未赋值变量。初始 A 只有 2 个值，B、C 各有 3 个，因此先选 A。

若并列，看度启发式

优先选择与其他未赋值变量约束最多者；如果初始三个域都为 {1,2,3}，B 连接两个邻居，会优先于 A、C。

再选值：LCV

Least Constraining Value：优先选择对未赋值邻居删值较少的取值。A=1 会从 B 删除 1；A=2 会从 B 删除 2，得分都为 1。按这里的约定先试较小值 1。

操作后推导：为什么要回溯，而不是宣布无解？

B=3 要求 C>3，但 C 的候选只有 1、2、3，因此三者都被删掉。失败的是当前分支。撤销 B=3 时，要把依赖这次赋值删除的候选恢复；A=1 仍然保留，所以 B=1 仍不可选。

再试 B=2，C 必须大于 2，只剩 3，得到 (A,B,C)=(1,2,3)。同一问题存在这个解，说明一个分支走不通不足以证明整个问题无解。只有所有需要尝试的分支都排除后，才有相应依据。

LCV 的分数可写成“所有未赋值邻居被立即排除的值数之和”。A=1 后，试 B=2 从 C 删除 {1,2}，得分 2；试 B=3 删除 {1,2,3}，得分 3。按较少删值的规则，先试 B=2。

仅执行与已赋值变量有关的前向检查，不自动做 AC-3。MRV 并列按未赋值邻居数，再按字母；LCV 并列按较小时段。

前向检查在赋值之后删去邻居中不兼容的值。弧一致性还检查未赋值变量之间的支持：对 X 的每个候选值，都要在相邻 Y 的域中找到满足二元约束的值。AC-3 会反复传播这种删值，直到稳定或某个域为空。上面的排班台采用前向检查，不会自动在未赋值变量之间继续传播。

只撤销该分支引入的赋值及其依赖删值。更早的有效赋值仍在，例如 A=1 仍然禁止 B=1。否则就会把已经不合法的候选重新当成可行。

约束描述了固定的任务要求。若结果还取决于另一方怎样回应，就需要把对方的选择也纳入推演。

当另一方也会选择

面对对手，“我能得到的最好结果”还取决于对方的回应。

学完这一节，你可以：计算 Minimax 回传值，用不等式解释剪枝，并比较对手假设的影响。

学习准备：先确认收益属于谁。所有终局数值都从 MAX 的角度给出，MIN 希望这些数值尽可能小。

这一步研究什么？

沿用：仍用实验室路线选择作为背景。

改变：进入双人阻拦小游戏：配送方 MAX 选路线，阻拦方 MIN 再选回应；终局分数只按 MAX 的收益记录。

要回答：面对会主动选择的对手，什么结果是自己能够保证的？

先写明对手假设

极大极小法（Minimax）先考虑对方会怎样回应，再选择自己能够保证的最好结果。下面始终用对 MAX 的收益来计分。

这个小游戏假设双方轮流行动、局面完全可见、结果确定、收益严格相反。MAX 最大化自己的收益，MIN 最小化同一收益。树中的分支表示路线与回应，叶子给定配送得分；它不是前面通道图的逐边展开。普通随机偏移不等于有意阻拦，后面的概率对手实验也会明确改换假设。

符号含义
U(s)终局 s 对 MAX 的效用；对 MIN 的效用为其相反数
V(s)在双方按上述目标最优回应时的回传值
Eval(s)截断搜索时，对非终局的近似评估
α，β搜索路径上 MAX 已有选择给出的下界、MIN 已有选择给出的上界

MAX 和 MIN 是任务中的角色名称。MAX 每次选择让自己的最终收益尽可能大的动作；MIN 使用同一张“对 MAX 的收益”表，却选择数值尽可能小的动作。我们并没有切换收益表的含义，所以看到 MIN 节点时要取最小值。

公式中的 max 和 min 分别表示在候选动作中取最大值、最小值。递归的意思是：当前节点的评价需要它的后继评价，而后继又可以用同一规则继续计算，直到已经知道效用的终局。计算从终局往回进行，才不会在未知值之间循环询问。

V(s) = U(s)　如果 s 是终局
V(s) = maxa V(T(s,a))　如果轮到 MAX
V(s) = mina V(T(s,a))　如果轮到 MINT(s,a)：执行动作 a 后的状态；递归地把子节点的结果向上回传。

推导与计算

剪枝依据是一条不等式

在刚才的演示中，根节点 MAX 已从左分支得到 3。右分支是 MIN，已看见一个终局 2；将尚未查看的另一个终局记为 z。无论 z 是多少：

V(右)=min(2,z)≤2<3
V(根)=max(3,min(2,z))=3

第一行来自“最小值不大于任何一个候选值”；第二行说明右分支无法改变根节点的最大值。因此可以不读取 z。这不表示右分支的精确值就是 2：若 z=−5，右分支值为 −5，根值仍为 3。

一般地，α 记录 MAX 已有选择能保证的下界，β 记录 MIN 已有选择给出的上界。检查一个后继、取得其回传值 v 后，更新方式为：

MAX 节点：α ← max(α,v)
MIN 节点：β ← min(β,v)
当 α≥β 时，可以停止检查该节点剩余后继。← 表示更新变量。根处初始化 α=−∞、β=+∞，表示尚未获得有限的界；界沿当前搜索路径传递。

演示中的条件就是 α=3、β=2。换访问顺序会改变什么时候得到这些界，因此影响查看叶子的数量，却不改变同一棵完整搜索树的 Minimax 值。剪枝处的返回值可能只是界，不应据此声称已算出该分支的精确价值。

如果在指定深度截断并用 Eval(s) 估值，α–β 保持的是这棵截断树的 Minimax 值；它不保证等于完整博弈的真实值。

停一下：剪枝有没有求出被剪分支的精确值？

已知根节点能得到 3，另一侧 MIN 已看见 2。若剩余叶子其实是 −5，根节点的选择会改变吗？

想好后查看解释

MIN 的真实值会是 −5，仍不会超过已经可得的 3。剪枝利用的是上界，未必需要知道被剪分支的精确值。

对手假设实验

“稳守”总得到 4；“尝试诱导”可能得到 −2 或 10。用 p 表示诱导后得到 10 的概率。


推导什么时候概率模型会选诱导
10p+(−2)(1−p) > 4
12p−2 > 4
p > 0.5

p=0.5 时两种动作的期望收益相等。Minimax 始终比较稳守的最坏值 4 与诱导的最坏值 −2，因此选择稳守。改变的是对对手的假设，而不是加法规则。

看不到终局时，评估函数在估计什么？

前面的叶子都是已经确定的终局收益。真实游戏可能无法在有限时间内搜到终局，于是先在某一深度停止，用 Eval(s) 估计这个非终止局面对 MAX 的价值，再按 MAX 取大、MIN 取小向上传递。

V̂d(s)=U(s)　若 s 已终局
V̂d(s)=Eval(s)　若未终局但 d=0
V̂d(s)=maxa V̂d−1(T(s,a))　若未终局、d>0，且轮到 MAX

估计会不会改变选择？

沿用左右两个 MIN 分支，真实终局分别是 3、5 和 2、9。先把它们遮住，只给两个截断节点估计值 2、6。

α–β 在相同截断树和相同叶值上，仍与普通 Minimax 给出相同结果；它不能让不准确的 Eval 自动变准确。搜索更深也不在所有问题上保证判断单调改善，因为截断位置和评估误差都会变化。

A* 的 h 估计到目标的剩余代价，通常越小越有希望；这里的 Eval 估计对 MAX 的收益，通常越大越有利。二者都使用任务知识，但估计对象和大小方向不同。
