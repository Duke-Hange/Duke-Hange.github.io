读公式时可以先翻译成动作

∑ 是“把这些项相加”，∏ 是“把这些项相乘”。P(X,Y) 问两件事同时发生；P(Y|X) 问已知 X 时 Y 的分布。若 P(X=1,Y=1)=0.4、P(X=1)=0.5，则 P(Y=1|X=1)=0.4/0.5=0.8。

ln 把乘法变成加法：ln(ab)=ln a+ln b。概率常小于 1，所以对数似然常为负数；−10 比 −20 大，表示更高的对数似然。先检查“比较什么、越大还是越小好”，再代数计算。

我们要学习的，究竟是哪一种结构？

核心

学到什么程度？
我能指出数据的一行是什么，并区分学结构、估参数、做预测与选行动。

贯穿案例 · 三盏灯先固定研究对象

三盏灯分别记为 X、Y、Z，亮为 1、灭为 0。一行记录是一轮同时读取的三个状态；每轮重新生成，轮与轮独立。我们要从观察判断哪些变量需要连接，随后才估计概率和预测。

假设记录中，X 灯亮时，Y 与 Z 也经常亮。这提示了关联，却不能直接告诉我们：X 是否与 Z 有直接连接，还是联系由 Y 解释？也可能有一个没有记录的共同控制信号。结构学习要比较能够解释这些依赖与独立关系的图。

真实研究里，一行可能是一名被试、一个试次或一秒记录。这些选择决定样本是否可以视为独立：同一被试的相邻时刻，通常不具备三灯案例中“每轮重新生成”的条件。观察单位应在学习结构之前明确。

社会研究中尤其要分清三种图。

“人 A 与人 B 关系好”是一条社会关系；“A、B 的行动在给定其他条件后仍有关联”是随机变量的依赖；“改变 A 的行动会改变 B”是干预主张。关系评分为零，不自动意味着概率图里没有边。

02 / 一 · 表示与概率

图、因子、分布与数据：同一个模型的四种视角

核心

学到什么程度？
我能说明图还缺哪些数值，才能计算一个具体事件的概率。

先修：概率加法与乘法。

贯穿案例 · 三盏灯从三盏灯中先取两盏

本章实验先看 X、Y：X 以一半概率亮，Y 以 r 的概率与 X 同状态。这里只改变表示方式与一致概率。第三盏 Z 会在下一章加入。

先只看 X、Y 两盏灯的亮灭。一个二元变量有两个状态，两个变量有 00、01、10、11 四种联合状态。完整模型要给这四种状态分配非负概率，并使它们加起来等于 1，因此有 3 个自由参数。图规定这些概率怎样分解，具体数值仍由参数给出。

从联合表走向局部规则

概率链式法则总允许写 P(X,Y)=P(X)P(Y|X)。对于更多变量，完整链式法则会让后面的变量依赖前面所有变量。贝叶斯网络利用条件独立把条件集合缩小为父节点集合 Pa(i)：

P(x₁,…,xₚ | G,θ) = ∏ᵢ P(xᵢ | xPa(i),θᵢ).

每个局部条件分布单独归一化，沿 DAG 相乘便得到归一化的联合分布。若没有 X→Y 这条边，二节点模型变成 P(X)P(Y)，要求独立；保留边则允许依赖，也允许参数恰好使两者独立。因此，“允许有联系”与“参数确实产生联系”应分开判断。

这解释了稀疏结构的统计价值。p 个二元变量的任意联合分布需要 2ᵖ−1 个自由参数；一张 DAG 中，节点 i 有 kᵢ 个二元父节点时，它需要 2kᵢ 个参数，总计 ∑ᵢ2kᵢ。例如五个节点的链需要 1+2+2+2+2=9 个参数，而任意五元联合分布需要 31 个。节省来自条件独立假设；若假设错误，节省也可能带来系统偏差。

进一步比较 · 无向图、势函数与因子图

核心路线先掌握 DAG 与条件概率表即可。这里补充其他表示，供下面切换图的实验和后续模型家族章节对照。

无向图与因子图各表达什么？

马尔可夫随机场用无向图表达条件独立，团是一组两两相连的节点。模型以团上的非负函数 φ 表达局部相容程度。这些“势函数”一般不是条件概率，需要统一除以配分函数 𝒵（用花体字母与三灯变量 Z 区分） 才得到概率。为使定义有效，𝒵 必须有限且为正。

P(x)= 𝒵⁻¹ ∏C φC(xC)，　𝒵=∑x ∏C φC(xC).

无向图中，给定 S 后若所有连接 A 与 B 的路径都被 S 隔开，就有相应的条件独立。严格正分布的全局马尔可夫性质与按团因子分解等价；存在零概率时，不能不加条件地使用这个等价结论。无向边也不等于“两者边际相关”：它允许在控制其他变量后仍有联系。

因子图进一步把分解中的每个因子画成方块，变量画成圆。变量与某个因子相连，表示它是这个函数的一个自变量。一个方块可以连接三个甚至更多变量，所以因子图能直接区分“一个三元因子”与“几个二元因子”。因子图是分解的表示方式，本身不把连接解释为因果箭头。

03 / 一 · 表示与概率

从一条链，到条件独立

核心

学到什么程度？
我能算出 0.68，并解释为什么控制中间变量后两端可以独立。

先修：概率相乘与条件概率。

贯穿案例 · 三盏灯补上第三盏灯

教学生成规则是 X 随机亮灭，Y 以 0.8 概率复制 X，Z 再以 0.8 概率复制 Y。讲解者知道生成规则；学习算法只获得记录，不直接获得真图。链与叉的分布对照用于说明这一信息差。

有向图用箭头连接节点；如果不能沿着箭头走一圈回到原点，就称为有向无环图（directed acyclic graph，DAG）。直接指向一个节点的节点称为它的父节点。贝叶斯网络由 DAG 和各节点的条件概率表组成；只有图还不能算出具体概率。

考虑 X → Y → Z。这里的箭头首先规定一个分解：先生成 X，再根据 X 生成 Y，最后根据 Y 生成 Z。对这个图，联合分布写成：

P(x,y,z) = P(x) P(y | x) P(z | y).

小写 x、y、z 表示变量的具体取值。主线设 P(X=1)=0.5，每一段以概率 0.8 复制上游的值，以概率 0.2 翻转。于是 P(1,1,1)=0.5×0.8×0.8=0.32。要求 P(Z=1 | X=1)，需要把未观察的 Y 的两种状态都考虑进去：

P(Z=1 | X=1)
= P(Y=1 | X=1)P(Z=1 | Y=1)
+ P(Y=0 | X=1)P(Z=1 | Y=0)
= 0.8×0.8 + 0.2×0.2 = 0.68.

同理，P(Z=1 | X=0)=0.32。X 与 Z 有边际关联，即使图中没有 X—Z 的直接边。但若已经知道 Y=1，无论 X 是多少，Z=1 的概率都是 0.8。知道 X 不再提供关于 Z 的额外信息。

X ⟂ Z | Y ⇔ P(x,z | y)=P(x | y)P(z | y)
对所有有正概率的条件值 y 成立。

符号 ⟂ 表示独立，竖线表示给定条件。条件独立是关于整个分布的陈述；一般情况下，零相关并不足以推出独立。对联合高斯变量，零偏相关才具有相应的条件独立含义。

为什么给定条件有时会制造关联？

在叉形 X ← Y → Z 中，给定共同原因 Y 也能阻断路径。而碰撞点 X → Y ← Z 相反：若 X、Z 原本独立，却共同决定 Y，只选取 Y=1 的情况，会使 X、Z 产生关联。

用一个最小例子：X、Z 是独立公平硬币，Y=1 表示至少一枚为 1。没有筛选时，P(Z=1 | X)=1/2。筛选 Y=1 后，若 X=0，就必有 Z=1；若 X=1，Z 仍有一半机会为 1。这叫“解释消除”：已知一个原因出现，另一个原因就不再是解释结果所必需的。

把三个小结构推广到整张图

d-separation 是图上的路径判据。把路径暂时看成不分箭头的连线：路径上的非碰撞点若被给定，路径关闭；碰撞点默认关闭，给定它或它的后代则可能打开。若 X 与 Z 之间所有路径都被条件集 S 阻断，就称它们被 S d-分离。

Markov 条件要求每个变量给定父节点后，与除父节点外的非后代变量独立；DAG 的概率分解体现了这一限制。满足该条件时，d-分离蕴含概率独立。反过来由独立推断图结构，还需要忠实性：分布中的独立不能来自路径效应恰好抵消等额外巧合。这一方向性差别是结构学习的关键。

迁移题：把两段复制概率都从 0.8 改为 0.6，X、Z 的关联会怎样？

P(Z=1|X=1)=0.6×0.6+0.4×0.4=0.52，P(Z=1|X=0)=0.48，两端差异从0.36缩小为0.04。给定Y后，Z的分布仍只由Y决定；联系变弱没有改变这条条件独立。

d-分离是一条“所有路径”的规则

检查 X 与 Y 时，先忽略箭头朝向找路径，再用箭头判断路径中间的节点是否为碰撞点。一个节点是不是碰撞点，取决于正在检查的这条路径：两条路径边的箭头都指向它才算。给定条件集 S，一条路径活跃需要同时满足两个条件：

  1. 路径上的每一个非碰撞中间节点都不在 S 中。
  2. 路径上的每一个碰撞点，其自身或至少一个后代在 S 中。

只要还存在一条活跃路径，图就没有保证 X 与 Y 条件独立。只有所有路径都阻断，才称 X 与 Y 被 S d-分离。这里的“活跃”是概率图中的术语，并不表示物质、信息或因果影响真的沿这条路径传播。

为什么需要 Markov 条件和忠实性？

Markov 条件给出一个方向：图的 d-分离意味着分布中的条件独立。它允许分布因为某些特殊参数而出现额外独立。例如 X→Y 的条件表两行完全一样，边存在也不产生依赖。忠实性排除这些额外独立，让我们可以反过来用分布中的独立性排除图中的路径。在多路径系统中，参数作用抵消也可能造成不忠实；接近抵消时，有限样本检验同样困难。

Markov：I(G) ⊆ I(P)；　忠实性与 Markov 合起来：I(G)=I(P).

I(G) 表示图蕴含的独立关系集合，I(P) 表示分布实际满足的独立关系集合。样本检验给出的只是这些分布性质的有误差证据，因此“真实独立性能够识别什么”与“这一批样本能否检测出来”是两层问题。

同一组独立关系，可以对应几张 DAG

对同一组标记节点，两张 DAG 马尔可夫等价，当且仅当它们拥有相同骨架和相同未屏蔽碰撞结构。骨架是去掉箭头后的连接；未屏蔽碰撞结构 X→M←Y 要求 X 与 Y 不相邻。这个定理讨论一般贝叶斯网络的独立性模型；若额外限制为某些非高斯、非线性或机制不对称的模型，可能获得额外方向信息，但那来自新增假设。

下面用 KL 散度衡量固定分布 P 与候选图重建的 Q 的差异：DKL(P‖Q)=∑ₓP(x)ln[P(x)/Q(x)]。本例各格概率均为正；这个量非负，P、Q 完全相同时为零。它用于比较概率表，不是在图上数错了多少条边。

观察到 X，与主动设定 X，有什么区别？

专题

学到什么程度？
我能解释 0.56 与 0.20 的差异来自哪一种人群加权。

先修：条件概率、分叉与等价类。

这个例子的任务：本章换成“提示—准备状态—完成任务”的因果假设模型。它专门比较观察与干预，不是三灯计数的另一次分析。

设 X 表示是否分配提示，Y 表示是否完成任务，U 表示任务开始前的准备状态。准备充分的人更可能得到提示，也更容易完成任务。观察 X=1 的人，相当于挑出一个准备状态比例不同的群体；主动把每个人的 X 都设为 1，则不会因此改变原来的 U 分布。

在一个具有因果解释的结构模型中，do(X=x) 表示把原来决定 X 的机制替换为常数 x。图上删去指向 X 的箭头，保留 X 对后续变量的作用及其他未被干预的机制。普通贝叶斯网络的概率分解本身并不保证这种机制替换有意义，因果解释需要额外的领域与设计假设。

观察：P(Y=1|X=x)=∑ᵤ P(Y=1|X=x,U=u) P(U=u|X=x).
干预：P(Y=1|do(X=x))=∑ᵤ P(Y=1|X=x,U=u) P(U=u).

第二行在本例成立，因为 U 已阻断 X 与 Y 之间的后门路径，且不是 X 的后代。将其用于真实数据，还需要相应的无未测混杂、干预与观察结果的一致性，以及所比较的 U 层中两种 X 状态都有支持等条件。看见一个公式并不能验证这些假设。

干预如何帮助结构学习？

如果 X→Y 与 Y→X 都能解释观察数据，理想的 X 干预可能把二者区分开：前者一般允许改变 Y 的分布，后者在没有其他路径时不允许。但干预目标、强度、有效性和测量误差都要进入模型；单次未发现变化也不等于证明没有边。干预提供新的证据类型，并不是让有限样本问题消失。

这些划分有交叉。贝叶斯评分可以用于搜索，也可以用于完整后验；混合方法把约束筛选与评分搜索组合起来。先明确目标，再选择计算路线。

若两个二元变量真的独立，联合概率应等于边际概率之积。设观察到 N 次，单元格 (a,b) 的次数为 Oab，行合计为 Oa·、列合计为 O·b。独立模型下的期望次数为：

Eab = N × (Oa·/N) × (O·b/N) = Oa·O·b/N.

例如频数表 [[40,10],[10,40]] 的总数为 100，行列合计都为 50，独立模型给每格 25 次。完整联合模型可以直接拟合四格比例。比较两者的最大对数似然，得到似然比统计量：

G² = 2[ℓ联合 − ℓ独立] = 2 Σa,b Oab ln(Oab/Eab)
= 2[80 ln(40/25) + 20 ln(10/25)] ≈ 38.549.

ln 是自然对数；它把连乘变成求和。某一格的贡献可以为负，但总 G² 非负。O=0 的项按极限记为 0。对独立、同分布观察且期望频数足够的常规情形，G² 在独立假设下近似服从自由度 (r−1)(c−1) 的卡方分布（r、c 分别为行、列变量的类别数），二元表自由度为 1。

p = P(χ²df ≥ G² | 独立假设下的近似分布).

p 值描述独立假设下出现当前或更极端统计量的概率，不是“独立假设为真的概率”。PC 常把 p>α 当作工作性的独立判定并删边；更准确地说，这只是没有拒绝独立，样本过少也可能造成这个结果。

给定 Z：先分层，再比较

将数据按 Z 的取值分层，每层计算 X 与 Y 的 G²，再相加。若每层都有完整支持，三个二元变量的条件检验有两层，每层 1 个自由度，总自由度为 2。稀疏、空层或结构性零会使简单公式与卡方近似失效，需要诊断支持情况，而不是照搬一个自由度。

PC：先删边，再判断哪些方向必须如此

核心

学到什么程度？
我能说出为什么删边、保存了哪个分离集，以及为什么保留未定方向。

先修：条件独立、碰撞点、G²。

贯穿案例 · 三盏灯从判断独立走向删边

三灯链中 X、Z 边际关联，但给定 Y 后独立，所以能删除 X—Z。此处为隔离算法逻辑，改用图上的理想独立性判据；它与前章有限样本的 G² 检验不是同一种证据来源。

开始时并不知道哪些变量直接相连，PC（Peter–Clark）先放入所有无向边。若找到一个条件集 S，使 X 与 Z 独立，就删除 X—Z，并保存 Sep(X,Z)=S。保存 S 并非记日志而已，它会决定后面怎样定向。

  1. 从空条件集开始。检验每对相邻变量是否边际独立。
  2. 逐层增大条件集。尝试大小为 1、2、… 的邻接变量子集，找到分离集就删边；没有足够邻居可继续时停止。
  3. 寻找未屏蔽三元组。若 X—Y—Z 存在，但 X、Z 不相邻，检查 Y 是否在 Sep(X,Z) 中。
  4. 定向碰撞点。若 Y 不在分离集中，定向为 X → Y ← Z；再传播由无环和避免新增碰撞点所要求的方向。

标准 PC 的理想正确性依赖：生成结构是 DAG、相关共同原因都被观测、无未处理的选择偏差、Markov 条件与忠实性成立、独立判断正确。使用本页G²判据时还要求适当的独立同分布抽样。有限样本检验会犯错；序列顺序与早期删边还可能影响后面的判断。PC-stable 固定每层的邻接集合，以降低骨架对变量处理顺序的依赖，但不会消除统计误差。

    Chow–Liu：为什么互信息可以变成边权？

    专题

    学到什么程度？
    我能解释互信息为什么能当树的边权，以及为什么必须跳过成环边。

    先修：联合概率、对数与频数。

    这个例子的任务：本章扩展为四个二元节点，专门展示生成树中的成环约束。边权来自总体分布，尚未加入抽样误差。

    若把候选图限制为树，每两个节点之间只有一条无向路径。任选根并将边朝外定向，就得到每个非根节点只有一个父节点的贝叶斯网络。这里选择根是概率分解的选择，本身不识别因果方向。

    互信息衡量联合分布偏离独立分布的程度：

    I(X;Y) = Σx,y p(x,y) ln[p(x,y)/(p(x)p(y))].

    它是非负的，等于零当且仅当独立。使用自然对数时单位为 nat。用频数比例代替概率得到经验互信息 Î。对条件独立检验章的 [[40,10],[10,40]]，Î=0.192745 nat，恰有 G²=2NÎ。这连接了“检验偏离”与“拟合改善”两个视角。

    把整棵树的似然拆开

    树分布可以写成各节点边际的乘积，再乘上每条边的关联修正：

    PT(x) = ∏i P(xi) × ∏(i,j)∈T P(xi,xj)/[P(xi)P(xj)].

    对 N 个观察取对数并求和，代入经验概率，第一部分只与各节点有关，不随树变化；第二部分正好是每条边的互信息：

    以 X→Y→Z 为例，P(x)P(y|x)P(z|y)=P(x,y)P(y,z)/P(y)，正好等于三个边际相乘后，再乘两条边的联合/独立比值。这个抵消过程对每棵树都成立。

    ℓ(T)/N = −Σi Ĥ(Xi) + Σ(i,j)∈T Î(Xi;Xj).

    Ĥ(X)=−Σp̂(x)ln p̂(x) 是经验熵。因此，最大化树似然等价于选择总互信息最大的生成树。Kruskal 方法按边权从大到小尝试加入，遇到会造成环的边就跳过，直到连接全部节点。

    设变量 i 有 ri 种状态，其父节点共有 qi 种配置。Nijk 表示父配置为 j、变量 i 取状态 k 的次数，Nij=ΣkNijk。每个条件概率表的最大似然估计就是该层内频率：

    θ̂ijk = Nijk/Nij,
    ℓ(G) = Σi,j,k Nijk ln(Nijk/Nij).

    例如一个二元 Y 没有父节点，只需一个自由概率；有一个二元父节点时，需要两行条件概率，每行一个自由参数。一张离散表格网络的参数总数为 d(G)=Σiqi(ri−1)。未观测到的父配置使最大似然参数无法直接估计；本节数据每格均有观察，避免这个额外问题。

    BIC：把增加的拟合与参数代价放到同一尺度

    SBIC(G) = ℓ(G) − ½ d(G) ln N.

    本页采用分数越大越好的约定。有些软件输出 −2ℓ+d ln N，称为 BIC 且越小越好，两者只差 −2 倍。比较时必须先统一符号。对两个二元变量增加一条边，参数数目增加 1，因此：

    ΔSBIC = NÎ(X;Y) − ½ ln N.

    在 N=100 的关联表中，似然提升约为 19.274，而复杂度代价为 2.303，差值约 16.972，支持连边。拟合提升若很小，复杂度代价可能让无边模型胜出。BIC 是一定正则条件下的渐近近似，有限数据中并不保证选中真实图。

      最大似然只看某张图能达到的最高拟合。贝叶斯方法给参数一个先验，再对所有可能参数的似然加权平均，得到边际似然：

      P(D | G) = ∫ P(D | θ,G)P(θ | G)dθ,
      P(G | D) = P(D | G)P(G) / ΣG′P(D | G′)P(G′).

      前一个式子处理参数不确定性，后一个式子处理结构不确定性。这里的积分是对概率表可能取值求平均，不是寻找使似然最大的那一组参数。

      先从一枚硬币理解积分

      若成功概率 θ 的先验为 Beta(1,1)，第一条成功的预测概率为 1/2。观察到成功后，后验为 Beta(2,1)，第二条成功概率为 2/3。所以有序数据“成功、成功”的边际似然为 (1/2)×(2/3)=1/3。最大似然会把 θ 设成 1，给这两次成功概率 1；边际似然保留了观察数据前对 θ 的不确定性。

      读下面的小例子，只需先用 Beta 的更新规则：把 a、b 分别约定为状态 0、1 的先验权重，观察到 n₀、n₁ 次后变为 Beta(a+n₀,b+n₁)，下一次取 0 的预测概率为 (a+n₀)/(a+b+n₀+n₁)。这是二元模型的共轭更新；伪计数表达先验强度，不是真实采样。注意上一段硬币例子按“成功、失败”排列，下面明确改按“0、1”排列。

      精确率=恢复出的真边数/所有恢复出的边数，召回率=恢复出的真边数/真实边数。没有预测边时精确率的分母为零，报告时要说明约定。SHD 通常计数边的增加、删除与反转，但方向反转算一次还是两次会随实现不同；比较前必须统一定义。对于仅能识别等价类的任务，更合理的是评价骨架、必然方向或 CPDAG，而不是任意选定的 DAG 方向。

      怎样把验证带回真实研究？

      1. 先定观察单位与划分方式。来自同一被试的多次记录不能随意分散到训练、测试两侧后声称检验了新被试泛化。时间序列应避免未来信息进入过去，重采样也要保留相关结构。
      2. 再做与任务相符的模拟。匹配样本量、变量状态数、噪声、缺失与候选模型，检查哪些机制容易混淆。若要检验模型选择，模拟时应覆盖多个候选生成机制。
      3. 把结构选择放在训练部分内部。若用测试集挑显著性阈值、惩罚或候选图，测试集就参与了选择；需要另一个独立评估集或嵌套流程。
      4. 区分三种概率。后验边概率来自指定模型、先验与数据；bootstrap 边频率来自指定重采样流程；本实验的恢复频率来自已知生成机制的重复模拟。它们的分母与含义不同。
      5. 报告不确定性与失败条件。给出未定方向、合理设置间的变化、基线比较与结论依赖的假设，使读者知道证据到哪里为止。

      同样的个人概率，为什么可能产生不同决策？

      专题

      学到什么程度？
      我能解释为什么相同边际概率下，关联有时改变行动、有时不改变。

      先修：联合、边际、条件概率与期望。

      社会研究中的一个核心问题是：被试怎样把关系评分变成对他人的预测？设公开成员为 a，另外两人为 b、c。Yb=1 表示 b 跟随 a，Yc 同理。已知评分 sab，可以提出候选映射 pb=σ(α+λsab)，其中 σ(u)=1/(1+e−u)。

      α 控制零评分的基准对数优势，λ>0 表示关系越好越容易跟随。定性指导语只支持变化方向，不能给出参数数值。参数可以由独立概率报告估计，也可以通过完整选择模型间接拟合；后一种方式可能与偏好和选择噪声互相补偿。

      候选机制额外假设与结构学习的关系
      局部独立P(Yᵦ,Y𝒸)=P(Yᵦ)P(Y𝒸)给定关系表征后的预测基线
      路径预测远端关系通过路径改变个人概率规定信息在关系图上如何使用
      固定边际关联个人概率不变，联合行动依赖改变隔离“关联本身”的价值
      联合相互作用例如 Ising 型联合分布，同时改变边际与关联更宽的候选模型，识别要求更高
      直接评价评分直接进入自己的选择规则不要求显式形成他人信念，作为竞争解释

      这些是针对任务的候选规格，不等同于已经确认的人类算法。以下先固定个人概率，把“是否考虑关联”单独拿出来。

      用一个数补齐四种联合状态

      令 pb=P(Yb=1)，pc=P(Yc=1)，q=P(Yb=1,Yc=1)。四格联合概率被唯一确定为：

      P₁₁=q，P₁₀=pᵦ−q，P₀₁=p𝒸−q，P₀₀=1−pᵦ−p𝒸+q.
      max(0,pᵦ+p𝒸−1) ≤ q ≤ min(pᵦ,p𝒸).

      上下界来自每格概率非负。独立时 q=pbpc。设行动 u 在四种状态的收益为 R00、R10、R01、R11，期望收益是概率加权平均。将四格概率代入并合并：

      Q(u)=R₀₀+(R₁₀−R₀₀)pᵦ+(R₀₁−R₀₀)p𝒸
      +(R₁₁−R₁₀−R₀₁+R₀₀)q.

      最后一个系数说明联合关联何时有价值。若它为零，固定边际后改变 q 不改变这个行动的价值。要改变行动之间的比较，还需要两种行动的这个系数不同。

      实验 15 · 信念不同，行动一定不同吗？

      固定 pᵦ=p𝒸=0.3。将 q 从独立值 0.09 改到 0.20，再切换收益规则，解释为什么有时最优行动改变，有时完全不变。

      收益单位为教学代币。另选的四状态收益均设为 10；跟随收益分别为 [0,20,20,26]，可加版本为 [0,20,20,40]。这是隔离机制的简化算例，不是完整实验支付规则。

      在联合规则下，ΔQ=Q(跟随)−Q(另选)=−10+20(pᵦ+p𝒸)−14q=2−14q。独立时 ΔQ=0.74，q=0.20 时 ΔQ=−0.80。两种信念给出不同建议，但收益差本身不大。可加规则下 ΔQ=2，改变 q 不影响决策。

      从最优行动到真实选择

      最佳回应是 u*∈argmax Q(u)。它允许并列。若要描述有噪声的选择，可以使用 P(u)∝exp[βQ(u)+b(u)]；β≥0 控制价值敏感性，b(u) 描述其他偏好。拟合得好不等于选择只由 Q 决定，也不证明人脑执行了这一算法。

      若目标是比较条件最优性，可以计算损失 L=maxuQ(u)−Q(uobs)。这始终是“在指定信念与收益规则下”的损失。比较心理机制还需留出预测、行为特征复现、参数恢复和模型恢复；尤其要检查任务条件是否能让不同模型产生可区分预测。
